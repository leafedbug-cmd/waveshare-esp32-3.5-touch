# Waveshare ESP32-S3 Touch LCD 3.5 Radio UI

PlatformIO firmware for the Waveshare ESP32-S3-Touch-LCD-3.5-C, combining its display, touch, sensors, audio, SD storage, nRF24 interface, and nRF52840 UART bridge.

## Find this repo again

Search for `Waveshare ESP32-S3-Touch-LCD-3.5-C`, `TARGET_SSID`, `NRF52_UART_RX`, `TCA9554`, or `RF24`.

See [Repository identity and recovery details](docs/REPOSITORY-IDENTITY.md).

## Build

```bash
pio run
pio run -t upload
pio device monitor -b 115200
```
